# BUG-003: Claude/Anthropic Model References Leak into Codex Deployed Files

| Field | Value |
|-------|-------|
| ID | BUG-003 |
| Status | Done |
| Priority | P1 (Impact 5 / Effort 2) |
| Release | 0.1.0 |

## Background

Multiple Claude/Anthropic references leak into Codex deployment artifacts:

1. **AGENTS.md** — `_strip_model_references()` is only called on prompts, not on AGENTS.md content. If any inlined rule contains `claude-sonnet` etc. outside the stripped "Subagent Model Selection" section, it survives.
2. **project-pr prompt** — Contains branded string `🤖 Generated with [Claude Code](https://claude.com/claude-code)` which is deployed verbatim.
3. **`_strip_model_references()` dead code** — The `anthropic` keyword replacement is commented out, never executes.

## Root Cause

The stripping pipeline was applied inconsistently: prompts go through `_strip_model_references()` but AGENTS.md does not. Brand strings (`Claude Code`, `claude.com`) were not considered as targets for stripping.

## Requirements

### R1: Apply `_strip_model_references()` to AGENTS.md content (MUST)

`_deploy_codex_agents_md()` MUST call `_strip_model_references()` on the final assembled AGENTS.md content before writing.

### R2: Strip Claude Code brand strings from all deployed Codex files (MUST)

The stripping pipeline MUST remove or replace:
- `Claude Code` → `AI Assistant` (or similar neutral term)
- `claude.com` URLs → remove or replace with generic text
- `Anthropic` brand references in non-technical context

### R3: Activate `anthropic` replacement in `_strip_model_references()` (MUST)

The commented-out `anthropic` replacement MUST be implemented. Replace standalone `Anthropic` brand references with neutral terms in model/tool context.

### R4: Add comprehensive grep-based E2E assertion (MUST)

E2E tests MUST `grep -ri` for `claude`, `anthropic`, `claude.com` across all deployed files and assert zero matches.

## Acceptance Criteria

### AC1: AGENTS.md has zero Claude model names

- **Given** a Codex deployment
- **When** `grep -i "claude-sonnet\|claude-haiku\|claude-opus" AGENTS.md`
- **Then** zero matches

### AC2: No Claude Code brand in prompts

- **Given** deployed `prompts/project-pr.md`
- **When** searching for `Claude Code` or `claude.com`
- **Then** zero matches

### AC3: Full deployed tree is Claude-free

- **Given** the entire `~/.codex/` tree after deployment
- **When** running `grep -ri "claude\|anthropic" ~/.codex/` (excluding the word "clause" or similar false positives)
- **Then** zero matches (or only false positives documented)

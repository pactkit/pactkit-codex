# BUG-002: project-sprint Should Not Be Deployed to Codex CLI

| Field | Value |
|-------|-------|
| ID | BUG-002 |
| Status | Done |
| Priority | P1 (Impact 4 / Effort 1) |
| Release | 0.1.0 |

## Background

`/project-sprint` is a multi-agent orchestration command that spawns a subagent team (system-architect, senior-developer, qa-engineer, repo-maintainer) to run an automated PDCA sprint cycle. Codex CLI is a single-agent environment — it cannot spawn subagents. Deploying this command to Codex is misleading and will fail at runtime.

## Root Cause

`_deploy_codex_prompts()` iterates over all entries in `COMMANDS_CONTENT` without an exclusion filter. Additionally, `_deploy_codex_agents_md()` hardcodes the sprint entry in the PDCA routing table.

## Requirements

### R1: Exclude `project-sprint.md` from Codex prompt deployment (MUST)

`_deploy_codex_prompts()` MUST skip `project-sprint.md` when deploying to the Codex profile. Define an exclusion set `CODEX_EXCLUDED_PROMPTS = {"project-sprint.md"}`.

### R2: Remove sprint entry from Codex AGENTS.md routing table (MUST)

`_deploy_codex_agents_md()` MUST NOT include the `| Orchestrate | /project-sprint | team-lead |` row in the PDCA routing table when generating for Codex.

### R3: Deployed prompt count adjusts to 10 (MUST)

After exclusion, Codex deployments MUST produce exactly 10 prompt files (not 11).

### R4: Define the exclusion set as a named constant (SHOULD)

The exclusion set SHOULD be a module-level constant so future commands can be easily added/removed.

## Acceptance Criteria

### AC1: project-sprint not deployed

- **Given** a clean Codex deployment to temp directory
- **When** listing `prompts/*.md`
- **Then** `project-sprint.md` is NOT present and exactly 10 files exist

### AC2: AGENTS.md has no sprint routing

- **Given** the deployed `AGENTS.md`
- **When** searching for `project-sprint`
- **Then** zero matches found

### AC3: E2E suite updated and passes

- **Given** updated test expectations (10 prompts instead of 11)
- **When** running full test suite
- **Then** all tests pass
